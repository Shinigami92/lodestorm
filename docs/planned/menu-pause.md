# Title view and pause panel (planned)

Decided 2026-10-17, built in M4 step 5 as PR A (see [`PLAN.md`](../PLAN.md)); the co-op and VR parts with M7 and M6. All values **TBD (playtest)**. Today there's no main menu: the game starts aboard in space with the player in cabin 1, quitting is the bed ("Sleep"), the settings terminal in cabin 1 holds the language and "Reset progress", `pause` (Escape, Menu/Options) only closes or steps back in menus, and nothing ever pauses the game (see [UI](../GAME_DESIGN.md#ui-in-the-world-not-on-the-screen)).

- **A title, not a menu:** with one save there's nothing to choose. The game opens on a **title view in the world**: the ship drifting in space, the game's name as a hologram beside it, "Press any button" below (translated). Any button and the camera glides into cabin 1, where the player gets up from the bed, so starting mirrors quitting ("Sleep"). The title view also covers loading the ship (no loading screen).
- **The pause panel:** `pause` with nothing open shows a holo panel beside the player, the camera moving in, in the same frame the wrist display uses today (its code is reused when the wrist goes, see [`player-display.md`](player-display.md)). It holds **Resume**, **Settings** and **Quit**; `pause` again or "Resume" closes it.
- **Does the world stop:** solo, yes: everything stops while the panel is open (aliens, the timer, the storm; wall-clock jobs like the furnaces run on anyway). In co-op, no: others are playing, the panel says so ("The game goes on"), and the player can still be attacked, like at any station. Solo, the game also pauses by itself when the window loses focus or the Steam overlay opens.
- **Settings in one place, reachable everywhere:** the settings live in the pause panel (language, the volumes from the sound effects, the suit ring's size and "Always show", later display and graphics), so they can be changed in the middle of a run. The settings terminal in cabin 1 shows the same settings (the same component) and keeps the one dangerous thing, **Reset progress** (solo only, three confirms as today).
- **Quitting:** "Quit" works like the bed: aboard it saves and quits to the desktop at once; during a run it warns first that the run is lost (one confirm). The bed stays as the in-world way to quit.
- **Credits:** a page in the settings (the team, the tools, the third-party licenses, the CC-BY sound sources generated from the sound manifest, see [`sfx.md`](sfx.md)), and the same at the title view after a while without input.
- **Co-op (M7):** guests get "Leave session" (back to their own ship), the host "End session"; joining a friend also works from the title view (accepting an invite through the platform's overlay).
- **VR (M6):** the pause panel floats in front of the player at a comfortable distance (see [`vr-view.md`](vr-view.md)); the title view is the same scene.
